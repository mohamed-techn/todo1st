# To-Do¹st

> A modern and efficient To-Do List application designed to help you organize your work and life.

## ✨ Overview

**To-Do¹st** is a modern task management application built with React and Vite.  
It provides a clean and intuitive interface for creating, organizing, searching, filtering, sorting, editing, and managing daily tasks efficiently.

The project focuses on a smooth user experience, reusable React components, and clean application architecture.

## 🚀 Features

- ✅ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Search tasks
- 🏷️ Filter tasks
- ↕️ Sort tasks
- 📊 Task statistics
- 🌓 Theme support
- 📱 Responsive user interface
- ⚡ Fast development with Vite
- 🧩 Reusable React components
- 🎯 Centralized task state management

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
- React Context API
- ESLint

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/mohamed-techn/todo1st.git
```

### 2. Navigate to the project

```bash
cd todo1st
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
